🔧 TECHNICAL DETAILS:

Architecture:
  • Model: AxisCalibration with CurvePoints array
  • View: XAML with TabView plus Canvas
  • Logic: Catmull-Rom interpolation plus event handlers
  • Storage: Windows LocalSettings (persistent)

Key Methods:
  • ApplyCurvePoints() - Interpolates between user points
  • CatmullRom() - Cubic spline calculation
  • CalculateCurveDeviation() - Deviation metric
  • SaveProfile() - Persistent storage
  • LoadAllProfiles() - Restore saved curves

Data Format:
  • Storage: Windows.Storage.ApplicationData.LocalSettings
  • Format: ProfileName=Point1,Point2,...Point11
  • Example: "Racing=0.0000,0.2500,0.4000,...,1.0000"
